# 统一认证与个人中心

## 1. 目标
本模块统一处理登录、注册、角色识别、个人资料维护与设置入口收纳，解决教师和学生入口分散、页面重复的问题。

## 2. 当前实现
- 页面右上角统一展示登录 / 注册入口
- 注册与登录共用一个弹窗，先选角色，再进入对应表单
- 登录成功后返回账号角色、资料信息和 Bearer Token
- 前端根据角色自动展示教师或学生功能视图
- 个人信息维护页面为 `/profile`
- 设置中心页面为 `/settings`

## 3. 注册规则
### 教师注册字段
- 姓名
- 工号
- 学院
- 专业方向
- 所属教研室
- 教学组
- 岗位称谓
- 邮箱
- 手机号
- 密码

### 学生注册字段
- 姓名
- 学号
- 学院
- 专业
- 年级
- 班级
- 邮箱
- 手机号
- 密码

## 4. 登录与账号约束
- 每个学生必须使用本人账号登录
- 账号体系下的提问、作业、反馈、学习记录与本人绑定
- 匿名发言不等于匿名登录
- 匿名发言只是在教师端和其他展示层隐藏公开身份

## 5. 设置中心结构
- 个人信息：查看和修改角色相关资料
- 外观设置：主题模式、主色、字体、皮肤
- 账号信息：当前账号、当前角色、退出登录

## 6. 当前边界
- 当前未接入短信验证码或第三方单点登录
- 当前未实现头像文件上传，仅保留头像路径字段
